# GeetPlays

Music streaming web app — mobile-first, dark, original Spotify-inspired design.

---

## Features

- **Home**: Netflix-style full-width banner carousel — auto-advance, bottom dot navigation, no arrows; Play and details actions.
- **Home carousels**: era carousels (90s / 80s / Gen Z), artist category carousels (Pop, Rock/Hip-Hop, Electronic/Indie, genre-based).
- **Language filtering**: English, Hindi, Marathi, Gujarati, Punjabi, Haryanvi, Tamil, Telugu, Kannada, Bhojpuri — filters banner, trending, recently played, albums, releases, recommendations, era and artist carousels.
- **Global player**: WebAudio synth engine, play/pause, next/prev, seek, shuffle, repeat off/one/all, volume + mute, like, queue, lyrics sync, full-screen mobile sheet, mini player, desktop bar.
- **Catalog**: 40 tracks, 23 artists, albums, playlists, moods/genres, trending top-10 with views/listeners/favourite markers.
- **Pages & functions**: Home, Search, Browse, Library, Playlist, Artist, Album, Song, Profile, Edit Profile, History, Notifications, Queue, Lyrics, Settings, Premium, Admin, Genre — all interactive, no dead controls.
- **Playlist management**: create, edit, delete, add/remove/reorder tracks, sort (title/artist/album/custom), find-in-playlist search.
- **Auth & admin**: login/signup/forgot/reset, guest mode, admin (`admin@geetplays.com` / `Admin@2026`), admin dashboard (stats, add/delete songs, suspend users).
- **Offline**: service worker app-shell + cover caching, localStorage for user data, WebAudio synth player.
